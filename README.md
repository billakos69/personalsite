 # Τα Projects μου

Στατική σελίδα με τα projects μου (APK, web εφαρμογές, εργαλεία).

- `index.html`: η δημόσια σελίδα
- `admin.html`: πίνακας διαχείρισης, φτιάχνει το `projects.json`
- `projects.json`: τα δεδομένα που διαβάζει η σελίδα

## Ενημέρωση
1. Άνοιξε το `admin.html`, κάνε τις αλλαγές και πάτα «Λήψη projects.json».
2. Αντικατάστησε το `projects.json` στο repo (Add file → Upload files).
